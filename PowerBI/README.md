# Power BI — Zomato Restaurant Analytics

## Data source

Use the cleaned restaurant-level dataset generated by the Python pipeline. The dashboard should use the same field definitions as the SQL analysis.

## Report pages

### 01 — Market Overview

**KPI cards**
- Restaurant Count
- Rated Restaurants
- Average Rating
- Average Cost for Two
- Online Order Adoption %
- Table Reservation Adoption %

**Primary visuals**
- Top cities by restaurant count
- Average rating by city
- Rating distribution
- Online-order adoption by city
- Price-band distribution

### 02 — City Analysis

**Slicers**
- City
- Area
- Price Band
- Rating Band
- Online Order
- Table Reservation

**Visuals**
- Restaurant count by city
- Average rating by city
- Average cost-for-two by city
- Online-order adoption by city
- Rating count by city

### 03 — Restaurant & Cuisine Analysis

**Visuals**
- Top cuisines by restaurant count
- Cuisine rating comparison
- Cuisine pricing comparison
- Rating distribution
- Restaurant detail table

The dashboard does not use a custom Performance Score or other weighted ranking model.

## Design principles

- Keep the report clean and recruiter-friendly.
- Use simple bar charts, tables, cards and a small number of useful comparison visuals.
- Use consistent units and number formats.
- Avoid overcrowding the dashboard.
- Keep the focus on restaurant supply, ratings, pricing, cuisine and digital-ordering information.
- Add a small methodology note: listed cost-for-two is a pricing field, not realized revenue.
- Add a data-quality note for unrated records and invalid coordinates where relevant.

## Validation checklist

Before publishing the report:

- [ ] Restaurant count reconciles to the cleaned dataset
- [ ] City count reconciles to Python/SQL
- [ ] Average rating uses the same valid-rating definition
- [ ] Online-order adoption reconciles to SQL/Python
- [ ] Table-reservation adoption reconciles to SQL/Python
- [ ] Average cost uses the same positive-cost definition
- [ ] Filters work correctly
- [ ] Dashboard screenshots are refreshed
